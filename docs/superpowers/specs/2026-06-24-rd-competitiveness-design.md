# 研发竞争力模块 — 设计规格说明书

> 日期：2026-06-24 | 状态：已确认 | 前置模块：行业对标（已完成）

## 一、目标与定位

### 1.1 模块目标

从「公司把资源投向未来的能力」切入，综合量化评分（研发投入维度）+ 定性标签（护城河判断），辅助识别真正具备技术壁垒的 A 股公司。

### 1.2 设计原则

- **竞争力视角**：默认展示高评分公司，排雷标记作为辅助信号叠加
- **实业优先**：UI 层预设行业组聚焦制造业 + 信息技术，零售/金融等低研发行业可查看但不前置
- **定量先行，定性跟进**：数据能自动算的（7 维评分）全自动；护城河等级需人工标注，提供框架和 Obsidian 双向链接
- **不替代判断**：评分是排序辅助，不是买卖建议

### 1.3 用户画像

具备基本面研究能力的投资者，已使用 Obsidian 做投资研究笔记，期望看板提供结构化筛选 + 深化入口。

## 二、数据管线

### 2.1 数据源

| 来源 | 路径 | 关键字段 |
|------|------|---------|
| CSRC 财务年度数据 | `上市公司财务年度合并90-24.xlsx` | `B001216000`（研发费用）、`A001219000`（开发支出）、`A001218000`（无形资产净额）、`B001101000`（营业收入）、`A001000000`（总资产） |
| 已有管线 | `screening_results.csv` | `Stkcd`、`ShortName`、`Indcd`、`Indnme`、`Year` |

### 2.2 派生指标（7 维）

| # | 指标 | 计算方式 | 权重 | 说明 |
|---|------|----------|------|------|
| 1 | **研发强度** | `(研发费用 / 营业收入) × 100` | 25% | 取最新年份 |
| 2 | **研发增速** | 3 年 CAGR（降级：3→2→1 年） | 20% | 同号且非零才计算 |
| 3 | **资本化健康度** | `1 - abs(资本化率 - 行业中位数) / 行业中位数`，clip [0,1]；资本化率 = 开发支出 ÷ (开发支出 + 研发费用) | 15% | 偏离行业中位数越远越差 |
| 4 | **持续性** | 近 5 年研发费用 > 0 的年数 ÷ 5 | 15% | 稳定投入 = 真投入 |
| 5 | **产出效率** | `营收 CAGR / 研发 CAGR`，clip [0,3] 归一化 | 10% | 每元研发带来的增长 |
| 6 | **定价权代理** | `毛利率分位数 × (1 - 毛利率变异系数)` | 8% | 持续高毛利 = 客户粘性 |
| 7 | **无形资产集中度** | `无形资产 / 总资产` × 行业组内分位数 | 7% | 有东西可「无形」才有壁垒 |

> 权重可通过 UI 滑块实时调整，以上为默认值。

### 2.3 归一化

- 所有维度在**当前行业组**内部计算百分位，转为 0-100 分
- 负值 / 异常值降级到 p10
- 金融业（银行/保险/券商）标记 `rd_applicable: false`

### 2.4 综合评分

```
综合评分 = Σ(维度分 × 权重)
```

### 2.5 管线输出

preprocess.py 新增 5.6-5.8 节，输出：

| 输出常数 | 内容 |
|----------|------|
| `RD_SCORES` | `{stkcd: {year, score, dimensions: {...}, flags: [...]}}` |
| `RD_HISTORY` | `{stkcd: [{year, score, dims}, ...]}` — 供贝叶斯跟踪图 |
| `INDUSTRY_RD_BENCHMARK` | 行业组级统计（中位数、分位数） |

### 2.6 边界处理

| 场景 | 处理 |
|------|------|
| 研发费用 = 0 或缺失 | 该维度 None，不影响其他维度评分 |
| 金融业 | `rd_applicable: false`，UI 不展示 |
| 上市不足 3 年 | 增速降级，持续性用实际年数 |
| 资本化率全行业为 0 | 健康度直接满分 |
| 数据年份 < 2 | 标记 `数据不足`，评分 N/A |

### 3.2 面板说明

| 面板 | 尺寸 | 内容 |
|------|------|------|
| **左-控制** | 250px | 行业组预设按钮 + 7 维权重滑块 + 年份选择器 |
| **中-榜单** | flex | ECharts 横向柱状图，按综合评分排序，Top N 可调 |
| **右-详情** | flex | 七维雷达图 + 时序趋势 +「护城河笔记」区 |
| **底-热力图** | 全宽 360px | 行业组 × 年份热力图，颜色深浅 = 研发强度中位数 |

### 3.3 行业组预设

| 组名 | 包含申万行业 | 标签颜色 |
|------|-------------|---------|
| 全部 | 所有非金融实业 | 默认 |
| 🔧 硬件与设备 | 半导体、消费电子、通信设备、计算机设备、光学光电子、元件 | 蓝 |
| 💻 软件与服务 | 软件开发、IT 服务、互联网电商、游戏、数字媒体 | 绿 |
| ⚙️ 高端制造 | 自动化设备、通用设备、专用设备、电池、光伏、风电 | 橙 |
| 🏗️ 材料与基础 | 金属新材料、化学制品、塑料、电子化学品 | 灰 |

### 3.4 交互流

1. 用户选择行业组 → 榜单 + 热力图联动过滤
2. 拖动权重滑块 → 评分实时重算、榜单重排
3. 点击榜单中的公司 → 右侧展开雷达图 + 趋势 + 护城河笔记
4. 底部热力图悬浮 → 显示行业名 + 年份 + 研发强度值
5. 年份切换 → 所有面板使用该年份数据（历史评分）

### 3.5 排雷标记（榜单行叠加）

| 标记 | 触发条件 | 视觉效果 |
|------|---------|---------|
| 🟡 资本化激进 | 资本化率 > 行业中位数 × 3 | 行背景浅黄 |
| 🟠 研发跳崖 | 今年 vs 去年研发费用降幅 > 30% | 行首橙色竖线 |
| 🔴 双杀 | 研发降 + 资本化率升（同时） | 行背景浅红 + tooltip |
| ⬜ 数据不足 | 有效年份 < 2 | 行灰色，评分 N/A |

## 四、技术护城河系统

### 4.1 分层设计

| 层级 | 来源 | 内容 |
|------|------|------|
| **L1 定量代理** | 数据管线自动计算 | 定价权代理、无形资产集中度（已纳入评分体系） |
| **L2 定性标签** | 用户手动标注 | 门槛等级、不可替代性、证据链、研究笔记 |

## 六、非功能需求

### 6.1 性能

- 首次 preprocess.py 运行预期 < 5 分钟（含 403MB xlsx 读取）
- 权重滑块拖动响应 < 100ms（纯前端重排）
- dashboard_data.js 增量 < 2MB（gzip 后 < 500KB）

### 6.2 边界与异常

- 金融业不参与评分，UI 中不出现
- 数据不足（< 2 年）的公司灰显但保留，不阻塞列表
- 行业组为空时显示引导提示「该组暂无符合条件的公司」
- moat_notes.json 缺失时不影响榜单功能，护城河区显示「暂无笔记」

### 6.3 可维护性

- 行业组预设配置为 JS 常量，方便新增/修改
- 权重滑块范围 0-100，标准化为百分比
- moat_notes.json 独立管理，与管线数据解耦
